# Credit Card Fraud Detection

A machine learning project that detects fraudulent transactions using Logistic Regression and Random Forest with SMOTE for handling class imbalance.

## Dataset

The dataset used is [Kaggle Credit Card Fraud Detection](https://www.kaggle.com/mlg-ulb/creditcardfraud). Download and place `creditcard.csv` in the root directory.

## Project Structure

- `fraud_detection.py` - Main script that loads data, applies SMOTE, and evaluates models.
- `requirements.txt` - List of dependencies.
- `README.md` - Project documentation.
