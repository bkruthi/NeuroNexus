# Credit Card Fraud Detection & Titanic Survival Prediction

This repository contains two machine learning mini-projects implemented using Python and scikit-learn:

## 1. Credit Card Fraud Detection

This project uses Logistic Regression and Random Forest with **SMOTE** to detect fraudulent credit card transactions from the `creditcard.csv` dataset.

### Features:
- Data balancing using SMOTE
- Model evaluation using confusion matrix, classification report, and ROC AUC Score

### Models Used:
- Logistic Regression
- Random Forest Classifier

---

## 2. Titanic Survival Prediction

Predicts passenger survival on the Titanic using the `tested.csv` dataset.

### Features:
- Handles missing data and categorical encoding
- Uses Random Forest with 5-fold cross-validation
- Predicts survival for new test data

### Model Used:
- Random Forest Classifier
